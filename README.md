# Swachh Mitra 🌍

**Smarter Waste Management. Cleaner Communities.**

Swachh Mitra is a **community waste management MVP** designed to reduce open dumping, improve collection efficiency, and encourage cleaner neighbourhoods.

---

## 🚀 Project Status
- Current Stage: **Frontend MVP / Prototype**
- Supabase integration: **Configured in code, but database setup not yet run on supabase.com**
- AI & IoT: Planned for future phases
- Hosting: Runs locally for demo

---

## ✨ MVP Features
- Municipal Dashboard → Overview of bins, alerts, and cleanliness rankings  
- Smart Bin Monitoring → Simulated fill‑level data with alerts  
- Location Input → Users & municipal authorities can enter area/location  
- Cleanliness Ranking → Prototype scoring of neighbourhoods  
- Sensor Simulator → Demo controls to simulate bin fill levels  

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript  
- **Backend (planned):** Supabase (PostgreSQL)  
- **Auth:** Supabase Auth (to be enabled after DB setup)
